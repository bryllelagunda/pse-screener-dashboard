    Connect your private results

    This page reads your screener's results from your private GitHub repository with a key that stays in this browser.

    Find it on GitHub's token page, next to the pse-screener key.

    1. Open GitHub's token page.
    2. Make a new key, or regenerate the pse-screener one; keep 90 days. A new key needs the pse-screener repository only, Contents: read and Actions: read and write. Copy the key.
    3. Paste it here, check the date, press Save key.
    4. Paste the new key everywhere you use the page: your other phone or computer, and the home-screen app if you added one (on iPhone it keeps its own copy). The old key stops working as soon as you regenerate it.

    Saved in this browser only. Your phone and computer keep separate lists.
